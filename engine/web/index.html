五角色方案技术说明

本附录只解释前面实际运行的客户方案 Agent、HS300 回测、夏普利归因和评审决策，不引入其他人员或独立示例。

  1. 意图转换客户用选择和文字表达偏好
  2. 配置校验Agent 仅生成白名单内的因子补丁
  3. 组合回测确认后的配置进入五角色 Pipeline
  4. 反事实归因32个角色联盟计算边际贡献
  5. 评审决策角色陈述仅供参考，由评审委员会确认应用

五角色与40因子

角色决策职责8个因子配置影响
行业分析师行业趋势与赛道筛选动量、均线、趋势效率、突破、区间位置改变行业候选排序
个股分析师个股反转与形态筛选反转、RSI、随机指标、回撤、下影线、下轨突破改变个股候选池排序
策略分析师收益特征、择时与仓位动量、跳空、日内收益、波动、ATR、偏度、峰度改变策略评分和目标波动率
量化分析师量价信号与候选优化量比、量能异常、成交额、量价相关、OBV、时序排名优化最终入选股票
风控分析师波动、回撤与集中度约束波动率、下行波动、ATR、振幅、回撤、偏度、峰度改变风险评分和持仓约束

因子配置约束

  • 默认12.5%仅是每个角色内部8因子的等权起点。
  • 每个角色内部权重归一化为100%，单因子最终不超过35%。
  • 波动率等风险因子按“低值优先”计分，回撤原始值按“越接近0越好”计分。
  • DeepSeek失败时明确显示规则回退；未确认建议不会进入回测。

回测与归因口径

  • 月末信号用于下一月持仓，避免使用未来信息。
  • 组合累计收益按各期收益连续复利计算。
  • v(S) = R(S) - R(沪深300)，五角色共有32个联盟子集。
  • 各角色夏普利值之和等于全组合相对沪深300的超额收益。

证据如何进入最终方案

最终方案 = 60% × 制度轨现行方案 + 40% × 夏普利证据轨。

客户方案、默认等权方案和沪深300使用同一回测口径对照；结果用于解释配置差异，不构成收益承诺。角色贡献陈述仅供评审参考，不参与建议份额计算；最终方案由评审委员会（或机构治理责任人）独立判断、调整并确认。
