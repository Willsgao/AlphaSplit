## 叙述逻辑（答辩主线）

用五句话串起来：

1. **痛点**：资管多角色协作创造收益，但奖金/考核仍靠固定比例「拍脑袋」，说不清谁贡献了多少。  
2. **理论跳板**：经典业绩归因（Brinson / 多因子 / CT&CS）本来就能按「决策维度」拆收益；维度可以从资产/风格，**延伸到组织角色**。  
3. **方法**：先做资产层归因 → 映射到角色 → 用 Shapley + 反事实/控制变量回测得到**贡献系数** → 作为考评锚点。  
4. **AI 不可替代处**：多智能体自动规划并执行反事实回测、评估方案是否达标、不达标则优化重试，把 Shapley 从公式变成可跑流水线。  
5. **落地边界**：系统输出的是**可解释权重/贡献系数**，不是自动发薪；建议「存量旧制 + 增量新制」双轨试点，人工确认终裁。

一句话定位：

> 不是自动分奖金，而是把「组合赚了多少」拆成「各组织角色贡献了多少」，给绩效考评提供可审计依据。

## 要解决什么问题

| 现状 | 缺口 |
|------|------|
| 收益能用 Brinson 等拆到配置/选股/风格 | 很少拆到**人 / 岗位 / 业务环节** |
| 奖金常按固定比例（如投研 ~30%、经理 ~60%、交易 ~5–10%） | 比例背后缺少可回测的贡献证据 |
| 监管推动考核更精细、更可归因 | 机构缺「贡献可计量」的标准化工具 |

本项目把归因对象从 **资产 / 因子 / 风格** 推进到 **组织角色**（行业分析师、个股分析师、策略分析师、量化程序设计者等），服务绩效考核与激励决策；**分钱是应用出口，不是主叙事**。

## 方法框架（三层 + 落地）

```
① 资产层归因
   Brinson / 多因子 / CT&CS 风格归因
   （配置 · 选股 · 择时 · 风格 · 交易 …）
        │
        ▼
② 组织角色归因
   角色 ←→ 归因项映射
   Shapley 贡献系数 + 反事实 / 控制变量回测
        │
        ▼
③ 绩效考评决策支持
   贡献系数 = 协商锚点 → 人工确认
   （可选：增量奖金池按新权重试点）
```

| 组织角色（示例） | 对应归因维度 | 经典对照 |
|------------------|--------------|----------|
| 行业分析师 | 行业配置 / 行业景气判断 | Brinson 行业配置 |
| 个股分析师 | 个股选择 / 风格内选股 | Brinson 选股 · CS |
| 策略分析师 | 仓位 / 风格择时 | CT · 仓位择时 |
| 量化程序设计者 | 交易执行与成本 | 交易及其他效应 |
| 基金经理（可扩展） | 总配置与统筹 | 资产配置 / 分层归因 |

辅助拆解（解释超额质量）：策略 Alpha / 行业·政策 / 偶然·宏观 —— 用于把「能力」与「运气」分开，避免把市场 beta 算进个人贡献。

## 实现主路径

```
初始化：多角色先验权重 / 旧制固定比例公式
        │
        ▼
多 Agent：结合投资场景，制定回测方案（控制变量 / 反事实子集）
        │
        ▼
自动（或先人工模拟）执行回测 → 得到切片结果
        │
        ▼
评估：不达标则修订方案重试；达标则收敛
        │
        ▼
输出：回测可视化 + 各角色贡献权重（考评锚点）
```

**落地策略（双轨制，降低机构阻力）**

| 资金池 | 比例（建议） | 做法 |
|--------|--------------|------|
| 存量 | ~60% | 沿用现有固定比例公式，不经 Agent |
| 增量 | ~40% | 按回测得到的动态角色权重试点 |

**工程推进顺序**：人工模拟回测跑通逻辑 → 再 Agent 自动化批量调度与解读。  
数据不足时：可用公开行情 + 量化策略（动量/财报等）「套壳」角色先验证链路，再替换为真实决策日志。

## 创新点（怎么跟评委说差异）

单点都有先例，**组合落点是新的**：

| 单点 | 先例 | 我们做什么 |
|------|------|------------|
| 收益归因 | Brinson、Barra、CT&CS | 作为资产层基础 |
| Shapley 绩效归因 | 组合/信号贡献计量文献 | 玩家定义为真实组织角色 |
| Agent 规划回测 | RD-Agent 等 | Agent 跑反事实回测，使 Shapley 可工程化 |
| 协商 + 人工确认 | 谈判智能体 / 合规实践 | 贡献系数 → 锚点，人做终裁 |

一句话区隔：**业界把收益拆给资产与风格；我们继续拆给组织角色，并做成可回测、可协商的考评基础设施。**

## 诚实边界

| 是 | 不是 |
|----|------|
| 贡献计量与绩效考评**决策支持** | 已上线的自动发薪系统 |
| Agent 规划回测 + 可解释贡献系数 | 精确因果的唯一真相 |
| 双轨试点、人工确认终裁 | 无人值守替代合规与 HR |
| 公开/合成数据验证机制 | 已替代机构内部脱敏决策日志 |
