# AlphaSplit 产品口径优化记录（2026-08-25）

## 1. 优化目标

项目统一定位为“投研角色贡献计量与广义价值分配决策支持平台”。

贡献计量结果可用于：

- 资金与研究预算；
- 数据、算力与工具额度；
- 项目机会与研究优先级；
- 人员投入与协作资源；
- 激励权益及其他机构自定义价值载体。

系统输出证据、建议份额和协商记录。分配对象、执行规则及最终方案由机构治理责任人确认，系统不自动执行分配。

## 2. 统一术语

| 原口径 | 新口径 |
|---|---|
| 狭义报酬导向 | 广义价值分配 |
| 可分配金额 | 可分配资源量 / 资源单位 |
| 新池奖励 | 夏普利证据池建议 |
| 确认执行动作 | 确认方案 / 确认应用 |
| HR 最终裁决 | 治理责任人 / 投委会人工确认 |

## 3. 修改范围

- 路演网页：首页定位、回测说明、双轨表格、协商文案和确认按钮；
- Agent：回测解读、五角色陈述、仲裁意见和运行态生成文本；
- 场景：HS300、量化因子复用、信用模型三个场景；
- 独立回测页面：角色权重与价值分配建议；
- 项目说明：`README.md`、架构摘要和双轨机制；
- 技术文档：5 份现有 Word 文档及其生成脚本。

为避免破坏既有调用，底层历史 API 字段名暂时保留；前端和对外说明均采用新的广义价值分配口径。
