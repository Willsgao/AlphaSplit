# 因子 Agent 互动功能优化记录

日期：2026-08-25

## 目标

在前端提供面向五个角色的自然语言配置入口。Agent 先生成因子/模块参数的变更建议，用户确认后，配置才进入实时回测；未修改的角色和因子继续使用默认值。

## 实现内容

1. 新增 `backtest/factor_config.py`，统一登记五角色 40 个因子、默认权重、模块参数上下限和规则型建议器。
2. 新增接口：
   - `GET /api/agent/factor-config`：返回角色、因子元信息和默认配置。
   - `POST /api/agent/factor-config`：根据自然语言返回变更预览，不执行回测。
3. 前端新增因子配置面板：
   - 展示五角色及当前因子权重；
   - 输入自然语言并生成差异表；
   - 用户点击确认后才更新当前配置；
   - 支持恢复默认配置。
4. 实时回测请求自动携带已确认的 `factor_config`；官方路演演示包仍使用预置结果，不宣称应用了自定义配置。
5. 回测结果记录生效的 `factor_config`，方便审计和结果解释；缓存键已包含完整配置，避免不同配置误命中同一结果。
6. 修复向后兼容问题：Agent 计划数据类的可选字段顺序调整；量化模块对旧版替身方法保留无关键字参数回退。

## 手动验证顺序

1. 结束旧的 AlphaSplit 服务进程，在项目目录前台启动新代码：

   `python -m engine.api.main --mode mock --host 127.0.0.1 --port 8000`

2. 浏览器打开 `http://127.0.0.1:8000/`，确认因子配置面板显示 5 个角色、40 个因子。
3. 输入“我偏稳健，希望加强风控并降低波动”，点击“生成调整建议”；确认出现差异表且“确认并应用配置”可用。
4. 点击“确认并应用配置”，再点击“实时回测”。路演演示按钮不会使用该自定义配置。
5. 回测完成后，在技术明细的结论摘要中确认显示生效配置 ID；同时可在浏览器开发者网络面板确认请求 `query.factor_config` 存在。

## 当前边界

当前 Agent 使用可离线运行的规则建议器，后续接入 LLM 时应保持相同的返回契约，并继续使用后端配置校验器；不能允许 LLM 直接写入代码或绕过用户确认。
